# 里山の、これから。（GitHub Pages 公開版）

長野・山あいの村を舞台に、限られた人手と資金を相談しながら野生動物との共存と収穫の両立を目指すシミュレーションゲームです。
Node.js などのバックエンドサーバー不要で、**GitHub Pages にアップロードするだけでそのまま公開・動作**します。

## ファイル構成
- `index.html` : メイン画面・カスタムSVG里山マップ・モーダルUI
- `style.css` : 和モダン・工芸調デザインスタイル
- `app.js` : ゲームロジック・シード付き乱数同期・QRコード生成
- `.nojekyll` : GitHub Pages のビルド処理をスキップするための設定ファイル

## GitHub Pages での公開手順

1. **GitHub で新しいリポジトリを作成**
   - リポジトリ名（例：`satoyama-game`）を決めて `Public` で作成します。
2. **このフォルダの中身をアップロード**
   - `index.html`、`style.css`、`app.js`、`.nojekyll`、`README.md` をリポジトリのルート（一番上の階層）にアップロード（または `git push`）します。
3. **GitHub Pages を有効化**
   - リポジトリの **Settings** → 左メニューの **Pages** を開きます。
   - **Build and deployment** の `Branch` で `main`（フォルダは `/ (root)`）を選択して **Save** を押します。
4. **公開URLにアクセス**
   - 1〜2分ほど待つと `https://あなたのユーザー名.github.io/satoyama-game/` で公開されます。

## 授業・ワークショップでの使い方
- **同じ条件でグループ対抗**：全員で同じ「村の合言葉（例：`nagano`）」を入力すると、同じ季節に同じ動物が出没する条件で挑戦できます。
- **URL・QRコード共有**：画面右上の **「URL・QRコード共有」** から、公開URLのQRコード表示や途中経過URLのコピーが行えます。
